## 🤕 The Problem

> *"Placements are just 3 months away... I don't know my exact DSA weaknesses, company-specific test patterns, or how to balance daily college attendance with interview prep. Where should I even start?"*

Modern college students and campus placement cells face critical bottlenecks every semester:

- **Fragmented Campus Portals**: Attendance is locked in one legacy portal, exam notices are taped on bulletin boards, and hackathon alerts are buried in noisy WhatsApp groups.
- **One-Size-Fits-All Preparation**: Students solve random coding questions without knowing whether their skills align with dream company hiring standards (Zoho, TCS, Amazon, Infosys).
- **High Counselor-to-Student Ratio**: Students lack 24/7 personal mentors who can debug their code line-by-line, evaluate mock interviews, and tailor 30/60/90-day revision roadmaps.
- **Placement Cell Blindspots**: Placement officers struggle with manual Excel sheets to track real student competency, assess batch readiness, and forecast drive clearances.

---

## 💡 The Solution

**NEROX AI** is an **Autonomous Multi-Agent Campus Intelligence & Placement Operating System** designed to unify student academic life and career acceleration.

- 🤖 **20 Specialized Autonomous AI Agents**: Each dedicated to a single campus or career domain—from debugging code to simulating HR & technical interviews.
- 🧭 **Intelligent Multi-Agent Orchestrator**: Students ask questions in plain English; the orchestrator dynamically analyzes intent and coordinates specialized agents behind the scenes.
- 🎯 **Targeted Company Readiness Engine**: Real-time company readiness scores, adaptive mock tests, Group Discussion coaches, and daily curated missions.
- 🏢 **Unified Campus Hub**: One glassmorphic dashboard for attendance records, smart digital library lookup, and automated event calendars.
- 👔 **Enterprise Placement Officer & Admin OS**: Microsoft Power BI-style dashboard for placement officers to monitor cohort analytics, search student directories, and broadcast company drives.

---

## ✨ Features

### 🎓 1. Student Command Center
- **Dynamic Learning Hub**: Smart Tutor explains complex concepts with intuitive diagrams and interactive examples.
- **Autonomous Coding Hub**: Real-time code execution, syntax/runtime debugging, and Big-O time & space complexity breakdowns.
- **Placement Intelligence Hub**: Tailored readiness scores for Zoho, Amazon, TCS, Infosys, and Cognizant with gap analysis.
- **Interview & GD Coach**: Interactive simulations with real-time feedback on articulation, technical depth, and logic.
- **Daily Prep Missions**: Gamified daily problem sets to build consistency, earn placement points, and maintain streaks.

### 👔 2. Placement Officer Hub (Power BI-Style Analytics)
- **Cohort Health Overview**: Instant KPI metrics on Total Students, Placement Eligible, and Batch Average Readiness.
- **Student Directory**: High-performance paginated table with multi-factor filters (department, year, readiness score) and CSV export.
- **Comprehensive Student Profile**: Granular drill-down into verified skill badges, radar charts, test history, and AI-powered placement forecasts.
- **AI Analytics Agent**: Natural language queries (*"Show students ready for Zoho"*, *"Who needs SQL improvement?"*).
- **Company & Drive Manager**: Post upcoming recruitment drives, eligibility cutoffs, and auto-generate AI company prep guides.

### 🛡️ 3. Super Admin Governance
- **Role-Based Access Control (RBAC)**: Secure multi-role authentication (Student, Placement Officer, Administrator) with JWT & bcrypt.
- **System Audit Trail**: Complete activity logs tracking logins, drive creations, and student updates.
- **Platform Diagnostics**: Live database connectivity status, user counters, and system configuration controls.

## 🚀 Quick Start

### 📋 Prerequisites
- **Node.js**: `v18.0.0` or higher
- **npm**: `v9.0.0` or higher
- **MySQL Database**: Local or remote (e.g. Clever Cloud / Aiven)
- **Google Gemini API Key**: [Get your free key from Google AI Studio](https://aistudio.google.com/apikey)

---

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/HareshK-14/NEROX-AI.git
cd NEROX-AI
```

---

### 2️⃣ Configure & Start Backend

```bash
cd backend
npm install
```

Create a `.env` file in the `backend/` folder:

```env
PORT=5000
NODE_ENV=development
CLIENT_URL=http://localhost:5173
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_mysql_password
DB_NAME=nerox_ai
DB_PORT=3306
JWT_SECRET=your_super_secret_jwt_key
JWT_EXPIRES_IN=7d
GEMINI_API_KEY=your_gemini_api_key_here
UPLOAD_DIR=uploads
```

Run database migrations and launch the backend server:

```bash
node migrate.js
npm run dev
```
> Server running at: `http://localhost:5000`

---

### 3️⃣ Configure & Start Frontend

Open a **new terminal** window:

```bash
cd frontend
npm install --legacy-peer-deps
npm run dev
```
> Application running at: `http://localhost:5173`

## 📡 API Endpoints

<details>
<summary><b>Click to expand full REST API specification</b></summary>

<br />

#### 🔐 Authentication & Roles
- `POST /api/auth/register` - Register a new account (`student`, `placement_officer`, `admin`)
- `POST /api/auth/login` - Authenticate credentials and receive JWT
- `GET  /api/auth/me` - Fetch authenticated user profile and permissions

#### 🧠 AI Orchestrator
- `POST /api/orchestrator/query` - Semantic multi-agent classification and unified execution
- `POST /api/ai/agent-action` - Direct execution of any of the 20 specialized agents

#### 👔 Placement Officer Analytics
- `GET  /api/officer/overview` - Batch KPIs (Total Students, Placement Eligible, At-Risk Counts)
- `GET  /api/officer/students` - Paginated student directory with search, filter, and sort
- `GET  /api/officer/students/:id` - In-depth student profile with AI placement probability forecast
- `POST /api/officer/ai-analytics` - Natural language queries on cohort performance

#### 🏢 Companies & Drives
- `GET  /api/companies` - List all recruiting companies and eligibility criteria
- `POST /api/companies` - Register a new company and schedule recruitment drives
- `POST /api/companies/:id/ai-prep` - Auto-generate AI company-specific preparation guides

#### 📢 Announcements
- `GET  /api/notifications` - Retrieve targeted student/officer notices
- `POST /api/notifications` - Broadcast drive announcements to specific departments
